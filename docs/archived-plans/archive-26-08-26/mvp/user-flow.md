## App user flow

### 1. Launch / Home

When the user opens the app, they first arrive at the **Home** screen for **MiTR Journey Yoga Studio**. The page introduces the studio with the message: “Discover the strength and soul within your everyday journey.” 

The Home screen acts as the main entry point and shows:

* A seasonal or knowledge-based graphic, which can change depending on the festival or campaign
* A promotion banner
* A contact shortcut
* Bottom navigation to the main app sections:

  * Home
  * Book Classes
  * Promotion
  * Instructor / Activities
  * Profile

### 2. View promotions

From the Home screen or bottom navigation, the user can open the **Promotion** page.

On this page, the user sees the available class packages, such as:

* 10 classes
* 20 classes
* Unlimited package
* Walk-in single class

The user can also see package validity periods and pricing. A payment QR code area is shown so the user can pay for the selected promotion or package.

### 3. Contact the studio

The user can open the **Contact Us** page from the Home screen or navigation.

This page provides:

* Google Maps link
* Studio address
* Phone number

This lets the user quickly find the studio location or contact the studio directly.

### 4. Browse class schedule

The user goes to **Book Classes** to see available yoga classes.

The schedule view allows the user to:

* Select a date
* Scroll left and right through dates
* View the month, such as June 2026
* Switch to a calendar-style view
* See available classes for the selected day

Each class card shows key information, such as:

* Class time
* Class name
* Instructor name
* Available slots
* Booking button

### 5. Open class details

When the user taps a class, they enter the **Class Detail** page.

This page gives more information about the selected class, including:

* Class image
* Class name
* Time
* Instructor

This helps the user understand the class before booking.

### 6. Book a class

After reviewing the class card or class detail page, the user taps the booking button.

The app should then register the user for the class, reduce the available slot count, and connect the booking to the user’s profile.

### 7. View instructors

The user can open the **Instructors** page from the bottom navigation.

This page shows a list of available instructors, such as:

* Kru Nop
* Master Shubham
* Master Anup

Each instructor has a profile image and short description. More instructors can be added later.

### 8. Register / create profile

On the **Profile** page, the user can register by entering basic details such as:

* Name
* Phone number

After registration, the profile becomes the user’s personal membership area.

### 9. Use profile QR code for class check-in

The Profile page includes a **QR code**.

The user can show or scan this QR code to check in when attending a class. This makes the profile function like a member pass.

### 10. Track class level and progress

The profile shows the user’s class level based on the number of classes attended.

The level system shown is:

* 1–20 classes: Cat
* 21–50 classes: Tiger
* 50–100 classes: Leopard

This creates a simple gamified progression system for members.

### 11. View recent activities

The user can see **Recent Activities**, which shows the latest two class-related actions.

For example, it may show:

* Recently attended class
* Recently redeemed points or rewards

### 12. View class history

The user can open **My Classes** inside the profile.

This section summarizes the classes the user has attended in the past, giving them a record of their yoga journey.

### 13. Rewards / collection flow

The later concept screens show a more gamified version of the app, where users collect “Tiger Toys” by attending classes.

The flow is:

* User attends classes
* User collects toy parts or progress
* User views their collection
* User unlocks milestones or rewards
* User can see promotions connected to attendance or referrals

This turns class attendance into a reward-based experience that encourages repeat visits.
